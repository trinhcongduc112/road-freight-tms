# Tra cứu đơn hàng công khai

:::info Trang đang biên soạn
:::

Khách hàng có thể tra cứu trạng thái đơn hàng **không cần đăng nhập** thông qua portal công khai.

## Mục lục dự kiến

- Truy cập trang `https://<domain>/track`
- Nhập mã đơn hàng
- Xem trạng thái realtime: vị trí xe trên bản đồ, ETA dự kiến
- Lịch sử hành trình của đơn

## Chia sẻ link tracking

Planner có thể bấm nút **"Chia sẻ link"** ở chi tiết đơn để copy URL gửi cho khách qua Zalo/SMS:

```
https://<domain>/track/<MA-DON-HANG>
```
